Declaração de Privacidade

Aplicativo CNC Code Maker (Microsoft Store) · versão 1.0 · atualizado em outubro de 2026

Resumo: o CNC Code Maker é um aplicativo de uso offline. Ele não coleta, não envia e não compartilha nenhum dado pessoal ou de uso. Nada sai do seu computador.

1. Dados coletados

O aplicativo não coleta dados pessoais, estatísticas de uso, identificadores de dispositivo, cookies ou qualquer outra informação. Não há conta de usuário, login, telemetria, analytics ou anúncios.

2. Dados armazenados somente no seu computador

Para sua conveniência, o aplicativo grava arquivos de configuração localmente, na pasta do seu perfil de usuário do Windows (nunca são enviados a servidores):

  • .cnc_code_maker_settings.json – preferências e configurações da máquina;
  • .cnc_code_maker_recent.json e .cnc_svg_recent.json – lista de arquivos recentes;
  • .cnc_code_maker_tools.json – ferramentas cadastradas.

Você pode apagar esses arquivos a qualquer momento sem que o aplicativo deixe de funcionar.

3. Arquivos abertos e gerados

Desenhos SVG, modelos STL e arquivos G-code (.nc) que você abre ou gera permanecem no seu computador; o aplicativo apenas lê e escreve nos caminhos que você escolher.

4. Fontes de texto

Ao listar as fontes TrueType/OpenType instaladas, o aplicativo consulta a configuração local do Windows. Essa consulta é feita apenas no seu PC e nenhuma informação é transmitida.

5. Internet e navegação

O aplicativo não exige conexão com a internet. O único momento em que algo é aberto fora do programa é quando você solicita o manual do usuário, que é exibido no seu navegador padrão a partir de um arquivo local.

6. Terceiros

Nenhum terceiro (inclusive a Microsoft) recebe dados do aplicativo além do que for necessário para a distribuição e atualização pela Microsoft Store.

7. Crianças

O aplicativo é adequado para todos os públicos e não coleta dados de crianças.

8. Alterações nesta declaração

Caso o aplicativo passe a tratar dados no futuro, esta declaração será atualizada e a nova versão será informada na página do produto na Microsoft Store.

Privacy Policy (English)

CNC Code Maker (Microsoft Store) · version 1.0 · last updated October 2026

Summary: CNC Code Maker is an offline application. It does not collect, transmit or share any personal or usage data. Nothing leaves your computer.

1. Data collected

The application collects no personal data, usage statistics, device identifiers, cookies, or any other information. There is no account, sign-in, telemetry, analytics, or advertising.

2. Data stored only on your computer

Settings and recent-file lists are saved as plain JSON files in your local Windows user profile (never uploaded): .cnc_code_maker_settings.json, .cnc_code_maker_recent.json, .cnc_svg_recent.json, .cnc_code_maker_tools.json.

3. Files you open or generate

SVG drawings, STL models and G-code files stay on your computer; the application only reads and writes the paths you choose.

4. Internet

Internet access is not required. The only external action is opening the built-in user manual in your default browser from a local file.

5. Children

The application is suitable for all ages and does not collect data from children.
